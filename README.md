# FOREST Lab Website
### Forest, Ecosystem Services and Traditional Knowledge Lab  
**CSIR-Institute of Himalayan Bioresource Technology, Palampur, Himachal Pradesh, India**

---

## Overview

This is the official website of the FOREST Lab at CSIR-IHBT, Palampur. The site serves as a public-facing showcase of the lab's research, team, publications, and activities.

**Live Site:** https://forest-lab-csir-ihbt.github.io/forest-webpage/

---

## Built With

- HTML5, CSS3, JavaScript (vanilla — no frameworks)
- Hosted on GitHub Pages
- Dynamic content (team members, publications, beyond science gallery, alumni) powered by Google Sheets

---
